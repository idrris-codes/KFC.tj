# KFC Tajikistan Photo Style Landing

Demo-лендинг для портфолио. Это не официальный сайт KFC.

## Сделано по просьбе

- дизайн в стиле присланного фото
- крупный hero-экран
- чёрно-красная палитра KFC
- убраны старые 3 карточки с цифрами
- добавлен большой блок доставки с иконкой телефона
- 2 номера доставки: 1400 и 1212
- кнопка выбора языка перед сайтом
- кнопка смены языка в правом верхнем углу
- ссылка на Instagram KFC Tajikistan
- ссылка на разработчика Sharipov Idris: https://www.instagram.com/idris.codes/

## Файлы

- index.html

- README.md

Открой `index.html` в браузере.
