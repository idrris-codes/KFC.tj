## Railway

1. Удали старые файлы из GitHub.
2. Загрузи эти 6 файлов в корень репозитория.
3. Нажми Redeploy в Railway.

В проекте нет локальных картинок и папок, поэтому Railway не должен открыть PNG вместо сайта.
