# KFC Tajikistan One File Final

Финальный проект: один HTML-файл со всем CSS и JS внутри.

## Файлы

- index.html
- package.json
- Procfile
- README.md

## Почему так

Нет папок, нет локальных картинок, нет отдельных CSS/JS файлов. Railway не сможет открыть PNG вместо сайта и не потеряет стили.
