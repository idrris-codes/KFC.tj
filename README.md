# KFC Tajikistan Landing — No Folders

Проект без папок. Только файлы в корне.

## Файлы

- index.html
- style.css
- script.js
- package.json
- Procfile
- README.md

## Почему без папок

В проекте нет PNG/JPG файлов, поэтому Railway не сможет случайно открыть картинку вместо сайта.

## Railway

1. Удали старые файлы из репозитория.
2. Загрузи эти файлы в корень репозитория.
3. Нажми Redeploy в Railway.
